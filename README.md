# Intrecci – sito vetrina

Sito vetrina di **Intrecci** di Veronica Fantini: borse fatte a mano in stile *minimal-pop*.

## Pagine

- `index.html` – il sito: Collezione (Capsule 01), Personalizza, Come nasce, Contatti
- `anteprima.html` – anteprima affiancata desktop + mobile

## Struttura

```
index.html
anteprima.html
assets/
  css/style.css
  js/main.js
  img/        foto della collezione, logo, immagine social
  video/      video "Come nasce"
robots.txt
sitemap.xml
site.webmanifest
```

Sito statico in HTML, CSS e JavaScript: nessuna libreria esterna, nessuna chiave API, nessun cookie di profilazione.
I caratteri tipografici (Bodoni Moda e Archivo) sono caricati da Google Fonts.
